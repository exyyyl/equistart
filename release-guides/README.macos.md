# EquiLauncher 1.3.1 — macOS

## Быстрый запуск

1. Распакуйте архив и откройте Terminal в полученной папке.
2. Один раз разрешите выполнение скрипта:

   ```bash
   chmod +x EquiLauncher.sh
   ```

3. Запустите лаунчер:

   ```bash
   ./EquiLauncher.sh
   ```

4. Выберите Equicord или Vencord в меню.

Если macOS блокирует файл после загрузки, откройте «Системные настройки → Конфиденциальность и безопасность» и подтвердите запуск.

## Автозагрузка

Выберите пункт автозагрузки в меню. EquiLauncher создаст LaunchAgent `~/Library/LaunchAgents/com.equilauncher.startup.plist`.

## Обновления и диагностика

При обычном запуске лаунчер предложит доступное обновление. Для записи подробного лога выберите пункт «Диагностика»; файл `EquiLauncher_Debug.log` появится рядом со скриптом.
