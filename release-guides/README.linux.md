# EquiLauncher 1.3.4 — Linux

## Быстрый запуск

1. Распакуйте архив и откройте терминал в полученной папке.
2. Один раз разрешите выполнение скрипта:

   ```bash
   chmod +x EquiLauncher.sh
   ```

3. Запустите лаунчер:

   ```bash
   ./EquiLauncher.sh
   ```

4. На главной выберите «Запустить Discord», затем Equicord или Vencord. После выполнения нажмите Enter, чтобы вернуться на главную. Пункт 0 на странице выбора мода возвращает назад, а на главной закрывает лаунчер.

Для работы необходимы `curl` или `wget`, а для автоматического обновления — `unzip`.

## Автозагрузка

Выберите пункт автозагрузки в меню. Будет создан файл `~/.config/autostart/equilauncher.desktop`.

## Обновления и диагностика

При обычном запуске лаунчер предложит доступное обновление. Для записи подробного лога выберите пункт «Диагностика»; файл `EquiLauncher_Debug.log` появится рядом со скриптом.
