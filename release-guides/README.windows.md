# EquiLauncher 1.3.0 — Windows

## Быстрый запуск

1. Распакуйте архив в отдельную папку. Не запускайте файлы прямо из ZIP.
2. Дважды щёлкните `EquiLauncher.bat`.
3. Если Windows покажет предупреждение, разрешите запуск PowerShell-скрипта.
4. Выберите Equicord или Vencord в меню лаунчера.

Запуск от имени администратора обычно не требуется. Discord должен быть установлен стандартным способом в профиль текущего пользователя.

## Автозагрузка

Выберите пункт автозагрузки непосредственно в меню либо запустите `Add-To-Startup.bat`. При входе в Windows лаунчер проверит мод и запустит Discord без показа интерактивного меню.

## Обновления

При обычном запуске EquiLauncher проверяет новые релизы. Обновление можно установить сразу или пропустить. Ошибка сети не мешает запуску текущей версии.

## Диагностика

Используйте пункт «Диагностика» в меню. Лог будет сохранён рядом с лаунчером в `EquiLauncher_Debug.log`.
