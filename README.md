# 🚀 EquiLauncher

При интерактивном запуске EquiLauncher проверяет последний GitHub Release. Если доступна новая версия, пользователь может установить её сразу или пропустить и продолжить работу. После успешной установки лаунчер автоматически запускает новую версию. В режимах автозагрузки (`--silent`, `--silent-vencord`) проверка не показывается и не мешает запуску Discord.

Скрипт для автоматической установки, обновления и запуска модов Discord (**Equicord** и **Vencord**) на Windows, macOS и Linux.

## 📦 Скачать

В релизе выберите архив для своей операционной системы:

- `equistart-v1.3.4-windows.zip`
- `equistart-v1.3.4-macos.zip`
- `equistart-v1.3.4-linux.zip`

Архивы macOS и Linux содержат один и тот же кроссплатформенный shell-скрипт, но публикуются отдельно, чтобы выбор загрузки был однозначным.

## 💻 Windows
1. Скачайте/скопируйте файл `EquiLauncher.bat` (и опционально `launcher.ps1`) в удобное место.
2. Просто запустите `EquiLauncher.bat` двойным кликом. На главной выберите раздел «Запустить Discord», «Диагностика» или «Автозагрузка», затем выберите мод:
   - Установку и запуск Equicord или Vencord.
   - Запуск в режиме отладки (с созданием лога ошибок).
   - Добавление выбранного мода в автозагрузку Windows.

### ⚙️ Автозагрузка (Windows)
- **Способ 1: Интерактивный (Рекомендуемый)**: Запустите `EquiLauncher.bat`, выберите «Автозагрузка» (3), затем Equicord (1) или Vencord (2).
- **Способ 2: Командная строка**: Запустите `EquiLauncher.bat --silent` (для Equicord) или `EquiLauncher.bat --silent-vencord` (для Vencord).
- **Способ 3: Вручную**: Создайте ярлык для `EquiLauncher.bat` в папке автозагрузки (`shell:startup`) с аргументом `--silent` или `--silent-vencord`.

В режиме автозагрузки EquiLauncher не закрывает уже работающий Discord без разрешения. Если патч слетел, появится диалог с выбором: перезапустить Discord и восстановить мод сейчас либо отложить восстановление.

## 🍎 macOS & 🐧 Linux
Скрипт `EquiLauncher.sh` адаптирован для macOS и Linux.

### Запуск:
1. Откройте Терминал в папке со скриптом.
2. Сделайте скрипт исполняемым (только при первом запуске):
   ```bash
   chmod +x EquiLauncher.sh
   ```
3. Запустите скрипт:
   ```bash
   ./EquiLauncher.sh
   ```
4. Выберите нужный пункт меню. Скрипт автоматически найдет Discord, загрузит необходимый CLI-установщик и применит патч.

### ⚙️ Автозагрузка (macOS & Linux)
- Выберите «Автозагрузка» (**3**) на главной, затем Equicord (**1**) или Vencord (**2**).
- На **macOS** скрипт автоматически создаст и загрузит LaunchAgent (`~/Library/LaunchAgents/com.equilauncher.startup.plist`).
- На **Linux** скрипт создаст стандартный Autostart Desktop Entry (`~/.config/autostart/equilauncher.desktop`).

В режиме автозагрузки EquiLauncher не закрывает уже работающий Discord без разрешения. Если патч слетел, появится диалог с выбором: перезапустить Discord и восстановить мод сейчас либо отложить восстановление.

## 🛠 Особенности
- **Кроссплатформенность**: Поддержка Windows (`.bat` / `.ps1`) и macOS / Linux (`.sh`).
- **Поддержка двух модов**: Выбирайте между Equicord и Vencord прямо в меню.
- **Интерактивное меню**: Удобный интерфейс без необходимости вручную прописывать параметры.
- **Переходы между экранами**: Каждый раздел открывается отдельно. После действия нажмите Enter, чтобы вернуться на главную; пункт 0 на странице выбора мода возвращает назад, а на главной закрывает лаунчер.
- **Режим отладки**: Позволяет найти причину ошибки, сохраняя детальный лог запуска.
